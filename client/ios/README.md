# Oshinobu — iOS

Нативный iOS-клиент: Swift, SwiftUI, CryptoKit, URLSession — без сторонних библиотек в ядре.
Протокол и формат на проводе — те же, что у Android (`client/android/client-kotlin`):
X3DH + Double Ratchet, REST + WebSocket. iOS и Android переписываются друг с другом.

Код начат 2026-10-26 и написан **вслепую** (на Linux-ПК нет Xcode и Swift): первая
задача на Mac — собрать, прогнать тесты и поправить ошибки компиляции.

## Структура

```
OshinobuCore/          Swift Package — ядро без UI (аналог :core на Android)
  Sources/OshinobuCore/
    Crypto/            X25519/Ed25519/HKDF/AES-GCM (CryptoKit), AAD конверта, X3DH,
                       Double Ratchet, шифры вложений (блоки 4 МБ), StoredIdentity
    Protocol/          InnerMessage (все типы), PeerCipher (сборка/вскрытие конверта)
    Net/               ApiClient (все REST-методы Android), WebSocketClient
    Storage/           Keychain/UserDefaults, KeyStore, SessionStore (с архивом сессий),
                       ChatStore (история — файлы под Data Protection), StoredMessage
    Service/           KeyedMutex, AckRegistry, SendQueueProcessor, PeerMessenger,
                       DeviceSetup, MessageRouter (самолечение, архив сессий, все типы)
    Support/           JSONValue (точные целые для AAD), Broadcast/StateValue
    OshinobuCore.swift фасад: вход, сессия, отправка текста, чтение
  Tests/OshinobuCoreTests/
    ProtocolVectorsTests  та же стенограмма, что у Android (protocol_transcript.json):
                          если зелёный — iOS понимает Android и наоборот
Oshinobu/              приложение SwiftUI
  project.yml          проект для XcodeGen (сам .xcodeproj не храним)
  Sources/             App, AppModel, темы (те же 5), вход/регистрация/TOTP,
                       главный экран (чаты/настройки/профиль), чат
  Resources/*.lproj    строки RU/EN — сгенерированы из Android strings.xml, ключи те же
```

## Сборка (на Mac)

```
brew install xcodegen
cd client/ios/Oshinobu && xcodegen        # → Oshinobu.xcodeproj
cd ../OshinobuCore && swift test          # ядро и векторы протокола (macOS 14+)
open ../Oshinobu/Oshinobu.xcodeproj       # iOS 17+, подпись — свой Team
```

## Решения

- **Минимум iOS 17** — `navigationDestination(item:)`, `defaultScrollAnchor`, к 2026 году это почти все устройства.
- **Хранение.** Ключи, сессии ratchet, очереди — Keychain, `AfterFirstUnlockThisDeviceOnly`:
  не уезжают в iCloud и резервные копии (после переустановки — новое устройство, как на Android),
  доступны при заблокированном экране (входящий пуш/звонок). История чатов — файлы в Application
  Support под `completeUntilFirstUserAuthentication` + кэш в памяти (Keychain не для больших данных).
- **Архив сессий** и запрет каскада автосбросов — как на Android с `+70`.
- Формат хранения на iOS свой (наследия Flutter нет), имена ключей те же, что у Android.

## Сделано (2026-10-26)

- **Ядро:** криптография, протокол, сеть (все REST-методы, WebSocket с переподключением,
  проверкой сессии, ожиданием для сигналов звонка; слежение за сетью через NWPathMonitor),
  хранилища, очередь отправки (ack, поздний ack, `rejected`, повтор при переподключении),
  PeerMessenger + регистрация устройства и пополнение prekey, MessageRouter (все типы, заглушки,
  самолечение, архив сессий), загрузка вложений (целиком / частями с докачкой), скачивание
  (ручная и авто-очередь, докачка потоком в файл, расшифровка, подтверждение серверу), звонки
  (CallManager: offer/answer/ICE, perfect negotiation, занято, 2 мин дозвона, таймаут шагов,
  история, пропущенный, отчёты `call_problem`), действия с сообщениями (реакции, правка, удаление
  у обоих, закреп, пересылка текста, повтор отправки, сброс шифрования, очистка/удаление чата),
  мьют, блокировка собеседника, аватары, обои чатов, стикеры (пак одним ZIP — свой ZipReader),
  блокировка приложения, автоотчёт об ошибках `auto_crash`.
- **Приложение:** вход, регистрация с TOTP, восстановление пароля и аутентификатора по коду из
  письма, список чатов (статус соединения, поиск по логину, аватары, превью, непрочитанные,
  закреп/мьют/удаление смахиванием и меню), чат (лента, ответ свайпом, статусы, контекстное меню
  с реакциями/ответом/копированием/правкой/закрепом/пересылкой/повтором/удалением у обоих, выбор
  нескольких сообщений, рассыпание при удалении (своём и собеседника), поиск по переписке, полоса
  закрепа с переходом, меню чата, «в сети»/«печатает…», обои (установка с кадрированием, «также у собеседника»), фото/видео из галереи и файлы,
  превью-кадр видео в ленте, сохранение на устройство и «Поделиться»,
  просмотр фото с масштабом и закрытием свайпом, видео в плеере, файлы в Quick Look, голосовые —
  запись удержанием и плеер, альбомы из нескольких файлов одним конвертом, кружки — запись с фронтальной камеры (зеркально, H.264) и
  воспроизведение в круге, стикеры PNG, анимированные WebP и TGS (lottie), панель стикеров с вкладкой «Недавние»,
  загрузка своего пака, просмотр пака из сообщения), профиль собеседника, свой профиль (фото, имя,
  статус, дата рождения), звонки (WebRTC + CallKit, экран звонка: микрофон, громкая связь, камера и её смена, выбор
  аудиовыхода (Bluetooth/наушники), видео собеседника на весь экран и своё окошком, картинка-в-картинке при сворачивании), повтор
  вложений, «зависших» при перезапуске, панель «Передачи» (отправка и обе очереди скачивания,
  отмена любой строки, процент выгрузки и скачивания), блокировка
  приложения (PIN + Face ID, таймаут), настройки (5 тем, язык RU/EN, приватность, почта для
  восстановления, выход).
- **Пуши:** VoIP (PushKit) — звонок сразу на экране CallKit, offer забирается по WebSocket после
  подключения; ответ до прихода offer принимается автоматически, сброс — через `/calls/decline` без
  WebSocket; нет offer за 30 с или пришёл `call_cancel` — экран закрывается; второй звонок во время
  разговора — «занято». Сообщения — обычный APNs с общим текстом (на экране приложения баннер
  скрыт). Токены — `POST /push/register-apns`, sandbox для сборок из Xcode (`DEBUG`).
